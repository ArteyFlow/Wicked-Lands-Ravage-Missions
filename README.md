# Wicked-Lands-Ravage-Missions
-----------------------------------------------------------------------------------
ArmA 3 Ravage Survival missions by ArteyFlow
-----------------------------------------------------------------------------------

Features:
- 50 player slots with random start and respawn points
- Roaming AI, both friendly and hostile
- Zombies
- AI Missions & Invasions which reward players with military-grade loot
- Money earned from killing zombies & AI, persistently saved across all of my missions
- Static traders to buy and sell weapons and gear (support for ArmA 3 + DLCs, CUP Weapons, NiArms, TRYK uniforms + vests, and RHS)
- Heli crash sites
- DayZ mod soundtrack
- Magazine Repack script
- Several other scripts from different authors which add a custom status bar, weapon holster, earplugs, and other features

 *** TO INSTALL THE MISSIONS:***
  1. Download repository
  2. Place the mission folders ("Ravage.Altis", "Ravage.Chernarus", etc) in your "Documents/ArmA 3/yourusername/mpmissions" folder (or "Documents/ArmA 3 - Other Profiles/yourusername/mpmissions" if you created another profile)
  3. Launch the mission by hosting a local server (either LAN or Internet)*
  4. Mission file will be found under the corresponding map name

*Missions should work on a dedicated server as well


Quickstart guide after installing the missions to set up multiplayer persistency and ground loot:
